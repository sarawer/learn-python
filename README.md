## 📁 Repository Structure

The repository is structured chronologically to follow the lectures in the playlist:

* **`lecture 1` - `lecture 9`**: These folders contain the code, concepts, and notes introduced in each specific video/learning session. As I progress, the topics advance from basic fundamentals to more complex Python concepts.
* **`practice`**: This folder contains hands-on exercises, mini-projects, and practice problems I've worked on to reinforce the concepts learned during the lectures.
